# Changelog

## 5.0.0-devkit-preview
- Fixed strict-profile validation so JavaScript spellings with BilaScript equivalents now emit `BILA-K001` diagnostics.
- Added a synchronized compiler-core workflow for CLI, browser and VS Code targets.
- Added a trilingual GitHub Pages playground and LAB-40 learning page.
- Added CI, Pages deployment, security guidance and regression coverage for Unicode and malformed input.
- Added standalone AST-first lexer/parser/compiler.
- Added function/if/for/while/do and modern expression grammar.
- Added arrays, objects, destructuring, spread/rest and arrows.
- Added class, try/catch/finally, switch and module syntax.
- Added BilaScript canonical global/member lowering.
- Added CLI compile/run/ast/check.
- Added Source Map v3 generation.
- Added browser DOM example.
- Added BilaScript Official Tools local VSIX with diagnostics, AST, compile, run and Node debug integration.
