# BilaScript Official Tools (preview)

VS Code tooling bundled with the same AST compiler core as the BilaScript DevKit.

## Features
- `.bila` syntax highlighting and snippets.
- AST syntax diagnostics with line/column locations.
- **BilaScript: Compile current file** -> `.js` + `.js.map`.
- **BilaScript: Show AST**.
- **BilaScript: Run current file**.
- **BilaScript: Debug current file** using VS Code's built-in Node debugger and generated source map.

This package is installable as a local VSIX. It is not a claim that the extension has already been published to the Visual Studio Marketplace.
